# Fichas de persona · Modelo de servicio

## Empresa de referencia

**Soluciones Digitales Popayán** es una agencia pequeña que atiende clientes comerciales y profesionales mediante soporte reactivo. Sus solicitudes se reciben principalmente por WhatsApp, correo y teléfono, y se registran manualmente.

## 1. Administradora de la agencia

| Campo | Información |
|---|---|
| **Rol** | Administradora de la agencia |
| **Contexto** | Dirige operaciones y coordina el equipo de soporte y mantenimiento de clientes. |
| **Edad y experiencia** | 35 años, con 8 años de experiencia en gestión de proyectos digitales. |
| **Objetivo** | Mantener los servicios de sus clientes funcionando y demostrar que la agencia cumple los acuerdos de atención. |
| **Necesidades** | Ver tickets activos, pendientes y vencidos; conocer el impacto y la prioridad de cada caso; conocer la carga de trabajo de cada técnico; comparar el rendimiento entre clientes y planes. |
| **Frustraciones** | Solicitudes en diferentes canales, posible pérdida o duplicación de información y falta de una visión única del tiempo de respuesta y solución. |
| **Comportamiento** | Revisa incidentes al inicio del día, consulta el historial antes de decidir y escala casos que afecten ventas, disponibilidad o reputación. |
| **Decisión clave** | El nivel de prioridad de un caso y el plan o atención correspondiente a cada cliente. |

## 2. Técnico de soporte

| Campo | Información |
|---|---|
| **Rol** | Técnico de soporte y mantenimiento |
| **Contexto** | Atiende fallas, cambios y solicitudes de configuración para varios clientes. |
| **Edad y experiencia** | 29 años, con 5 años de experiencia en desarrollo web y mantenimiento. |
| **Objetivo** | Resolver cada caso con el menor tiempo posible y dejar evidencia clara del trabajo realizado. |
| **Necesidades** | Recibir tickets con descripción, impacto, cliente y prioridad; ver accesos, errores y recursos; registrar inicio y resultado; identificar los casos prioritarios. |
| **Frustraciones** | Solicitudes con poca información, búsqueda de datos en diferentes canales y atención manual fuera de horario. |
| **Comportamiento** | Ordena casos por impacto económico y urgencia, comunica avances y registra causa, solución y tiempo empleado. |
| **Decisión clave** | Si un caso puede resolverse de inmediato, requiere revisión adicional o debe escalarse. |

## 3. Cliente PyME

| Campo | Información |
|---|---|
| **Rol** | Cliente PyME |
| **Contexto** | Tiene un restaurante, consultorio o negocio pequeño y depende de su sitio web para vender o atender clientes. |
| **Edad y experiencia** | 41 años, con experiencia básica en uso de herramientas digitales. |
| **Objetivo** | Que el sitio o servicio funcione correctamente y que cualquier problema se resuelva sin complicaciones. |
| **Necesidades** | Reportar fallas con pocos pasos; saber qué ocurre y cuándo terminará; recibir respuestas sin términos técnicos; recibir la atención acordada según su plan. |
| **Frustraciones** | Incertidumbre sobre el estado del caso, necesidad de usar varios canales para obtener información y tiempos de espera que afectan sus ventas. |
| **Comportamiento** | Describe el problema con un mensaje breve, adjunta evidencia y valida la solución mediante el funcionamiento real del sitio. |
| **Decisión clave** | Continuar con el plan contratado, solicitar prioridad o pedir una explicación del incidente. |
